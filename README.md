## 🌍 Why Loreon Learning Exists

Africa has **70 million people** who want careers in technology but lack access to affordable, locally relevant training. Global platforms teach in contexts that don't match African industries, infrastructure, or job markets — learners earn certificates but still can't get hired, and dropout rates are staggering because **people learn alone**.

Loreon Learning was built to close that gap. We combine four things no other platform offers together:

| | |
|---|---|
| 🎯 **Africa-first curriculum** | Built around local industries — fintech in Lagos, agritech in Nairobi. You build real systems, not generic to-do apps. |
| 🤖 **AI that actually helps** | Assesses your level, builds a personalised path to your career goal, and tells you exactly what to learn next. |
| 👥 **You don't learn alone** | Every learner joins a cohort with peers, mentors, and live tutors. Accountability is built in, not bolted on. |
| 💼 **Learning leads to jobs** | We measure success by **job placements**, not course completions. Portfolio + skill profile matched to open roles. |

> **Our values:** Accessibility · Excellence · Community · Innovation · Empowerment

## 🐳 The DevOps Learning Path

A complete, hands-on journey from **absolute beginner → job-ready / senior DevOps engineer**, taught on **Docker running on an AWS EC2 Linux instance** — real infrastructure, no toy sandboxes. Every lesson pairs a clear explanation with a **live demo** and a **weekly hands-on project**.

Track your progress by ticking the boxes as you go. 👇
